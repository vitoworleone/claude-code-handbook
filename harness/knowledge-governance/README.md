# Knowledge Governance

> 如何让领域知识、规则、案例与 AI 工作流持续积累，而不演变成新的文档、规则和 Skills 屎山。

这个专题讨论的不是某个模型或工具的具体用法，而是一个更底层的问题：当 AI 开始参与高频、长期、带领域判断的工作时，组织如何保存知识、把知识交给 AI，并持续验证它是否仍然有效。

## Reading Map

1. [Verification Loops](./verification.md)：为什么 AI 的生成、验证与修复应构成循环，以及人应保留哪些决策权。
2. [Subjective Evaluation](./subjective-evaluation.md)：如何把领域专家的主观判断，从真实审核案例逐步沉淀为可复用的评审标准。
3. [Decision Traces](./decision-traces.md)：如何在不打断心流的前提下，保存 AI 协作中的关键决策与依据。
4. [Knowledge Governance](./knowledge-governance.md)：如何治理文档、规则、案例和 Skills，避免知识库本身成为新的负担。

## Core Thesis

> AI 不需要阅读组织的全部知识；它需要在当前任务中找到正确、足够新、可验证的上下文。

稳定的 AI 协作能力来自四件事：领域事实、专家判断、负反馈和验证机制。模型、框架和 prompt 会演进；能持续产生价值的是一套能够将经验转为可检索知识、再转为可执行约束的系统。
